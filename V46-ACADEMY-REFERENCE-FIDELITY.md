# Сверка модели с выбранным образцом

Образцом служит предоставленный пользователем экран урока 2.1: вкладка «Примеры», шаг 4/4, 48 свечей, поддержка 98–100, сопротивление 108–110 и шесть пронумерованных подходов. Цены, порядок свечей, подписи зон и компоновка этого экрана сохранены. Цвета продолжают следовать выбранной теме дневника.

Обнаруженное расхождение при обычном открытии: первый шаг показывал только 12 свечей, второй — 26, поэтому повторные реакции и вся форма диапазона отсутствовали на экране. Кроме того, после закрытия примера сохранялся номер шага, но вкладка возвращалась на «Теорию».

Исправления:

- На первых трёх шагах 2.1 видны все 42 исходные свечи с теми же зонами и шестью отметками. Меняются объяснение и подсветка нужных подходов. Шесть свечей продолжения появляются на последнем шаге.
- Сохраняется выбранная вкладка. Старые и некорректные значения безопасно открывают теорию. При восстановлении практики ответ и уже раскрытое будущее заново скрыты.
- Для проверки именно выбранного экрана есть ссылка `academy-preview.html?lesson=2.1&tab=examples&theme=midnight`. Явный параметр вкладки имеет приоритет над сохранённым видом; прежние ссылки на дополнительные практикумы работают.
- Обновлены версии ресурсов и кеш приложения: v15.

Проверка:

```powershell
node tests/academy-reference-fidelity.cjs http://127.0.0.1:8767/academy-preview.html
node tests/academy-studio-price.cjs
node --test tests/academy-terminal-chart.cjs
$env:TD_REFERENCE_WIDTHS='320,1440'
node tests/academy-reference-browser.cjs http://127.0.0.1:8767/academy-preview.html
node tests/academy-studio-browser.cjs 390
node tests/academy-reference-readability.cjs http://127.0.0.1:8767/academy-preview.html
node tests/academy-preview-smoke.cjs http://127.0.0.1:8767/academy-preview.html
$env:TD_THEME_WIDTHS='390'
$env:TD_THEME_LESSONS='2.1'
node tests/academy-theme-browser.cjs http://127.0.0.1:8767/academy-preview.html
```

Новая проверка сравнивает все 48 закрытий с образцом и фактическую геометрию тел свечей с ценовой шкалой SVG. Подтверждены неизменность геометрии во всех 18 темах на 320/390/1540 px, масштаб, выбор свечи, переключение разметки и исходов, сохранение вкладки и отсутствие раскрытого будущего при возобновлении практики. Снимок 1540×1240 сверён с пользовательским образцом.

Регрессия: все 81 урок пройдены на 320 и 1440 px, отдельно на 390 px; проверены 146 дополнительных упражнений, конспекты, условия завершения, разделение аккаунтов и ошибки сохранения. Проверка читаемости всех уроков: 186 полей/ячеек, пересечений подписей зон с отметками — 0. В 18 темах дополнительно проверен контраст урока 2.1.

Все проверки используют изолированные синтетические профили. Изменений схемы, RLS, рабочей базы и реальных записей нет.
