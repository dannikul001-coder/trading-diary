# Обучение по согласованному референсу

## Что изменилось

Все 81 урок получили общий интерфейс: тёмная страница, зелёный акцент, крупная модель, объяснение рядом и вкладки «Теория», «Примеры», «Практика», «Конспект». На телефоне материалы выстраиваются в одну колонку. Программа курса и соседние уроки доступны без потери доступа к восьми этапам развития.

Каждый урок использует собственный предметный renderer: 27 ценовых, 28 индикаторных и 26 расчётных/ситуационных моделей. Дополнительные разборы, термины, тренажёры и 146 упражнений из источников сохранены. Конспект и выбранный ответ остаются в форме при переключении вкладок. Прогресс хранится в браузере отдельно для аккаунта, как и до обновления.

График поддерживает выбор свечи указателем, ползунком, кнопками и клавишами ←/→, Home/End; масштаб, включение разметки и несколько подписанных зон. Изменения шага сохраняют ручной выбор только для доступной общей истории. Переход к скрытой практике сбрасывает состояние раскрытого будущего. Плавные переходы учитывают системную настройку уменьшения движения.

Урок 2.1 переработан отдельно: 42 свечи истории, поддержка 98–100, сопротивление 108–110, три нижние реакции и два верхних подхода, затем шесть свечей продолжения. Самостоятельная задача использует другую историю. Обе ветки сохраняют исходные границы; все числа в объяснениях и ответах относятся к показанным данным.

Каталог оформлен в том же стиле. Счётчики используют фактическое прохождение; после завершения урока сразу обновляются процент и отметка. Обновлена версия кэша приложения и добавлены новые стили в список файлов для работы без сети.

## Как воспроизвести проверку

Из корня репозитория:

```text
node --test tests/academy-terminal-chart.cjs tests/academy-studio-price.cjs tests/academy-studio-indicators.cjs tests/academy-studio-decisions.cjs
node --test tests/academy-content.cjs tests/academy-book-material.cjs tests/academy-source-practice.cjs tests/learning-attachment-labs.cjs tests/learning-indicators.cjs tests/learning-math.cjs tests/learning-labs-advanced.cjs
node tests/academy-studio-route.cjs
node tests/academy-reference-browser.cjs
node tests/academy-reference-readability.cjs
node tests/academy-studio-browser.cjs
```

Для браузерных проверок необходимы Chrome и Playwright. Пути можно задать через `TD_BROWSER` и `TD_NODE_MODULES`.

Дополнительно проверены по локальному HTTP-серверу `academy-preview-smoke.cjs`, `academy-beginner-browser.cjs` и `academy-source-material-browser.cjs`. Их первым аргументом передаётся URL страницы `academy-preview.html`.

## Результат

- 49 модульных проверок пройдены, проверка каталога и восьми этапов пройдена.
- Новый браузерный suite: 81/81 урок на 320, 390, 1100 и 1440 px. Проверены четыре вкладки, реальные модели, ответы, конспекты, ограничения завершения, обновление счётчиков и отсутствие горизонтального переполнения.
- Существующий suite: 81/81 урок на 1100, 390 и 320 px, возобновление, старый прогресс, изоляция аккаунтов, порядок сохранений и ошибки хранилища.
- Проверены действия с графиком, скрытый префикс после повтора, неправильные и правильные ответы, дополнительные практикумы и прямые ссылки на материалы.
- Проверена читаемость 186 ячеек и полей по всем урокам: контраст не ниже 4,5:1. На 320/390/1440 px подписи зон не пересекаются с маркерами, верхняя полоса не перекрывает управление графиком.
- Учебные проверки не отправляли запросов к базе. Миграции, RLS, production-база и реальные пользовательские записи не изменялись.

Основной вход — раздел «Обучение» в дневнике. Независимый просмотр: `academy-preview.html?lesson=2.1`.
