# Trading Diary — обновление дизайна второго дневника

**Дата:** 25 октября 2026  
**Ветка:** новый дневник автоматических сигналов, visual iteration 2  
**Исходник:** пользовательский архив `Новинка.zip`  
**Содержание релиза:** комплексный редизайн существующего второго дневника без переписывания основного приложения и без SQL-миграций.

## 1. Что реально изменено

- `index.html`: экран выбора дневника, двухуровневое рабочее пространство второго дневника, боковая навигация на ПК, мобильная навигация, новый мастер настройки, блок выбора темы, SVG-символы.
- `automated-diary.css`: собственная цветовая система, Obsidian / Ivory / Neon, состояния элементов, адаптивные карточки, таблицы, формы, календарь, диаграммы, диалоги, пустые состояния, уведомления и доступные фокусы.
- `js/automated-diary.js`: обновлённые экранные шаблоны и взаимодействия, Dashboard на реальных данных, график капитала, распределения P&L по времени, навигация, темы через localStorage, фильтры сделок, поиск по заметкам, календарь с фильтром по дню, отдельный экран финансов, экспорт CSV, диалог закрытия сделки.
- `sw.js`: обновлено имя кеша, чтобы свежие CSS и JS второго дневника включались в список офлайн-ресурсов PWA.

## 2. Изменения по экранам

1. **Выбор дневника:** читаемый экран с явным разделением режимов.
2. **Обзор:** доступный баланс, торговый P&L, доходность относительно начального баланса, win rate, количество, резерв, бонусы, средняя ставка, максимальная торговая просадка, серии W/L, капитал с учётом реализованных результатов и денежных движений, статистика за периоды, распределение по часам и дням, последние сделки и будущие события.
3. **Сделки:** новая таблица, цветовые статусы, отдельная форма, поиск по заметкам, фильтры открытых/закрытых, CSV, подтверждение суммы возврата в диалоге.
4. **Бонусы:** сводные показатели, фильтр по статусу, карточки бонусов и форма нового получения.
5. **Сигналы:** календарь месяцев с датами событий и фильтрацией списка по дню, список событий и пояснение ограничений уведомлений.
6. **Финансы:** отдельная страница пополнений/выводов, капитал с резервом, состав баланса и временная лента реализованных результатов, бонусов и финансовых операций; экспорт CSV.
7. **Настройки:** превью тем и параметры второго дневника. Проверка аномалий работает только на уже загруженных записях.
8. **Первый запуск:** новый визуальный мастер с сохранением старой схемы данных.

## 3. Неприкосновенные части

- `style.css` основного дневника **не менялся**.
- Файлы `js/app.js`, `js/storage.js`, `js/auth.js` и другие исходные модули основного дневника **не менялись**.
- Supabase SQL-миграции **не изменены и не выполнены**.
- Существующие пользовательские сделки **не просматривались, не изменялись и не удалялись**.
- Форма и смысл вычисления доступного баланса и реализованного P&L сохранены относительно исходного второго дневника.
- Интерфейс не демонстрирует придуманные реальные сделки или фиктивные рыночные индикаторы. Демонстрационные данные использовались **только в изолированном браузерном тесте** и не включены в приложение.

## 4. Реальные проверки

- Архив-источник: проверка CRC ZIP пройдена.
- `node --check` для обновлённого JavaScript: пройдено.
- Изолированный браузерный тест Chromium с имитатором Supabase: все шесть разделов открываются без JS-ошибок.
- Протестированы темы Obsidian, Ivory, Neon, формы сделки/бонуса/сигнала, фильтрация, календарь, мобильные настройки, создание сделки и первичная настройка дневника в тестовой среде.
- Ширины экрана: 320, 360, 390, 768, 1024 и 1520 px — без горизонтального переполнения документа в изолированном браузерном тесте.
- HTML/CSS просмотрен скриншотами в Chromium на компьютере и телефоне.

## 5. Что НЕ проверено / остаётся отдельным функциональным этапом

- Работа с **реальным** Supabase, авторизацией и RLS (исследована лишь структура исходного SQL).
- Регрессионное тестирование основного дневника с реальными 2855 сделками и ПК ↔ телефон.
- Точность денежных операций под многопоточными запросами: исходные вычисления JavaScript через Number по-прежнему нуждаются в отдельном финансовом аудите.
- Изменение/удаление ранее созданных бонусов и сигналов, история редактирования сделки, категории сигналов, повторения и серверные уведомления — не реализованы этим визуальным обновлением.
- Фоновая доставка уведомлений: только старая схема при открытой вкладке; браузерное разрешение не гарантирует доставку.
- Изоляция данных на живой базе и устойчивость к одновременным финансовым операциям не проверялись.
- Полный тест производительности с тысячами записей в браузере и CI-тесты не выполнялись.

**Решение для публикации:** сперва протестировать архив на копии / тестовом окружении с Supabase и проверить основной дневник. На GitHub не публиковать без подтверждения пользователя.
