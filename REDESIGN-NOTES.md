# Trading Diary 2.0 — Structural Redesign v2

## Что изменено

Это не косметический редизайн старой боковой панели. Навигационная модель полностью перестроена:

- боковой desktop-sidebar удалён из рабочего пространства;
- верхняя командная шапка стала главным каркасом приложения;
- навигация перенесена в двухуровневую горизонтальную рабочую панель;
- разделы сгруппированы по приоритету: основные рабочие экраны и дополнительные инструменты;
- sidebar оставлен только как мобильный drawer;
- основной контент получил новую сетку с асимметричными рабочими областями;
- кнопки получили фиксированную геометрию, `box-sizing`, единые высоты и безопасные flex/grid-правила;
- фоновые паттерны находятся на отдельном слое и не проходят через текст кнопок;
- состояния выбранных кнопок имеют собственную непрозрачную поверхность;
- внешний вид Settings оставлен функционально совместимым с существующим JS, но визуально перестроен под новую систему.

## Совместимость

Существующие идентификаторы DOM, необходимые для текущего JS/Supabase слоя, сохранены. Это позволяет менять конструкцию интерфейса без переписывания всей логики данных.

## Проверки

- `node --check js/app.js` — OK
- `node --check js/auth.js` — OK
- `node --check js/settings.js` — OK
- `node --check js/storage.js` — OK

Браузерный headless-прогон в среде разработки зависает на уровне Chromium runtime, поэтому визуальное соответствие не объявляется полностью автоматизированно проверенным.
