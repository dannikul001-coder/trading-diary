# План обучения Trading Diary

Курс для начинающего: сначала экран и одна свеча, затем риск, структура, инструменты и собственная проверка. Все 81 урок доступны в каталоге; подробные методы не нужно открывать скрытым переключателем.

Каждый урок: понятная идея → показ по шагам → отдельный числовой разбор → новый пример для самостоятельного решения → проверка и конспект.
