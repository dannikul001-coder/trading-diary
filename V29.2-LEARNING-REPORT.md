# Trading Diary V29.2 — Learning UI Stabilization

## Scope
- Preserve the existing Learning categories, lessons, progress model, and admin learning CMS.
- Improve learner navigation without introducing a new lesson architecture.
- No destructive Supabase migration is required.

## Changes
1. Added Learning status filters: All / Not started / In progress / Completed.
2. Recommended card now prioritizes an in-progress lesson, then the next unfinished lesson.
3. Lesson cards show progress for lessons in progress.
4. Learning roadmap shows completed lessons and category completion percentage.
5. Next-step panel uses the first in-progress lesson before the next untouched lesson.
6. Existing categories, lesson records, progress records, and admin lesson editor are retained.
