## Техническая реализация

- Добавлена `supabase/migration_v31_curriculum.sql`.
- Миграция не удаляет категории или уроки.
- Категории создаются/обновляются по уникальному `slug`.
- Уроки создаются/обновляются по уникальному `slug`.
- Все материалы получают статус `published`.
- Существующие сделки, Auth, RLS, sync и `learning_progress` не изменяются.
- Для будущего расширения в `content` сохраняются дополнительные поля источника: `sourceTitle`, `sourceDuration`, `sourceOrder`.

## Важно

Миграцию нужно выполнить в Supabase SQL Editor. После этого опубликованные материалы появятся в текущем Learning UI.
